## 3. Tamarin, N=7, q=5, 2q-N=3 (second abstraction: qpt128_quorum_n7.spthy, generated by gen_n7_votes.py)
Deliberately different encoding: no crypto terms; signatures are ideal authenticated facts !Vote(seat,K,v) creatable only by the
seat (honest, one candidate per K) or by the adversary holding !Corrupted(seat); 21 explicit 5-subset Accept rules; 7 Register rules.
Results (tamarin_output_n7_perlemma.txt; ~125 s of every isolated run is fixed --prove overhead for this 32-rule theory):
VERIFIED: sanity (8 steps), A1 (23), A2 (4685), D2 (6), D2b unordered corollary (6), C3 evidence reachable (4). NOT COMPLETED within
2.5 GB / 6-7 min per lemma: A (heap), B (timeout 420 s), C1 (timeout), E2 (heap), D1 (heap, 593 s); E1, C2 only in the batch run that
timed out at 1200 s. No lemma falsified. The N=7 two-certificate claims are therefore established only by the exhaustive checker (5).

## 4. ProVerif (qpt128_quorum.pv = C=2, qpt128_quorum_C1.pv = C=1) - UNEXECUTED
Same abstraction as N=4 Tamarin (ideal message-recovering signature, table of registered keys, `restriction` enforcing one candidate
per (seat,K), verifier needs three verifying signatures of pairwise-distinct seats, extractor takes two conflicting signatures of
one seat). ProVerif cannot count corruptions, so C is fixed per file by publishing exactly C keys. Expected (NOT observed) results:
C=1: A, A', C, D, D' true; "no conflicting pair" TRUE (this is the meaningful test of B); Evidence unreachable.
C=2: A, A', C, D, D' true; "no conflicting pair" FALSE with the s0/s1 double-signing attack; B trivially true. Syntax: ProVerif >= 2.04.

## 5. Bounded checker (bounded_checker.py -> bounded_checker_output.txt; third, independent, exhaustive model)
N in {4,5,7,10}, q = floor(2N/3)+1 -> (q,2q-N) = (3,2),(4,3),(5,3),(7,4); every C in 0..N; every corrupt subset for N<=7 (WLOG
{0..C-1} for N=10 by seat symmetry); every honest choice (none/v1/v2); every certificate = every subset of size >= q of the seats
holding a signature; every certificate pair. Every N: conflicting pair exists iff C >= 2q-N (E/B); A holds for every certificate;
minimum intersection over all conflicting pairs = exactly 2q-N (C); honest seat named by extraction: never (D). Boundary assertions
(C=2q-N-1 -> no pair; C=2q-N -> pair whose intersection is all-corrupt) pass for N=4,5,7,10; three-candidate re-check for N<=5 passes.

## 6. Modeling findings (artifacts of the models, not protocol violations)
- Lemma-statement bug caught before any run: the first D2 required Corrupt(s) before BOTH acceptances. A seat may honestly sign v1,
  be corrupted afterwards, and have its v2 signature forged, so the correct claim is `k < i | k < j`; the original would have been
  falsified by that legitimate trace. Tamarin, the .pv files and the checker all use the corrected statement.
- Tractability rewrites, none changing the trace set: (i) generic 3-variable Accept rule + 4-way seat-name disjunction -> OOM
  (kept as qpt128_quorum_generic.spthy, unproven); replaced by the 4 explicit 3-subset rules. (ii) `Eq(verify(..),true)` gives 2^3
  equational variants per rule -> replaced by pattern-matching sign(<K,v,seat>,sk) against the registered pk(sk) ([no_derivcheck]);
  equivalent under the `signing` theory. (iii) `[reuse]` of A1/A2 made Tamarin split Signed/Corrupt for all six abstract signers
  before resolving any Accept node (2^6 branches; heap exhaustion): A2 is now hidden (hide_lemma) in every two-certificate lemma,
  which close via D2 on concrete shared signers. (iv) N=7: per-seat Register rules instead of a 7-way name disjunction (A2 went
  from heap exhaustion to 4685 steps) and one !CertSig(c,K,v,seat) fact per signer so Extract matches the shared seat directly.
- N=7 C2 is stated "for any two signers s,t of certificate 1 there is a common signer u outside {s,t}" (guarded; equivalent to
  |intersection| >= 3); the direct `Ex s t u` form makes Tamarin case-split trivially-true disjuncts.

## 7. Discrepancies between the models
None found. Tamarin N=4 (symbolic signatures), Tamarin N=7 (ideal votes; single-certificate lemmas + D2 only, section 3), ProVerif (expected only)
and the exhaustive checker agree: boundary at C = 2q-N, intersection >= 2q-N, intersection is a subset of the corrupt set.

## 8. Honest limits
- Tamarin proves A-E for N=4 (and N=7 per section 3) with unboundedly many coordinates, candidates, certificates and sessions,
  but for those N only. Nothing here proves N=64, q=43 except via the same counting structure (two q-subsets of an N-set share
  >= 2q-N elements) which the checker verifies exhaustively for N <= 10 and which is the one-line theorem the implementation
  relies on (22 shared signers for the ratified parameters).
- The symbolic models assume EUF-CMA-ideal ML-DSA, honest seats that never double-sign a coordinate, unique seat registration
  and a verifier that checks seat-identity distinctness; transcript/seat-index binding, duplicate-signer checks and coordinate
  encoding in the implementation are outside this layer and belong to the code audit. ProVerif results are expectations only.
