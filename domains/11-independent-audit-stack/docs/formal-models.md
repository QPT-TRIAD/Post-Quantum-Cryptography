# The formal models, and what each lemma establishes

Three models of the same abstraction are recorded here, plus one unexecuted skeleton:

1. **Tamarin** (1.12.0 with Maude 3.5.1) — two theories, N = 4 and N = 7.
2. **`formal/bounded_checker.py`** — a third, independent model in plain Python set enumeration.
3. **ProVerif** — two models, recorded as **unexecuted** (the audit host had no ProVerif) but
   executed for this repository with ProVerif 2.05; see §4.
4. **`formal/frame_b0.ec`** — an EasyCrypt skeleton, unexecuted, proof `admit`ted.

## 0. The abstraction all three models share

One coordinate `K` with candidates `v1`, `v2`; N seats, threshold q, `2q − N` the guaranteed
intersection. A corrupt seat holds a signature on `(K, v)` for **every** candidate (the adversary
obtains any signature from it); an honest seat signs at most one candidate per `K`. A certificate
for `v` is any set of ≥ q pairwise-distinct seats with a signature on `(K, v)`; extraction on a
conflicting pair outputs the signer intersection, and a seat in that intersection holds two
signatures on conflicting transcripts (slashable evidence). The properties are A (acceptance
implies q distinct signers, each honest or corrupt), B (a conflicting pair implies ≥ 2q−N corrupt
seats), C (the intersection exists, has ≥ 2q−N seats, and evidence is reachable), D
(non-frameability: nobody named by extraction is honest), E (the boundary: below 2q−N no conflict,
at 2q−N one exists).

## 1. Tamarin, N = 4, q = 3, 2q − N = 2

`formal/qpt128_quorum.spthy`; recorded run `formal/tamarin_output.txt`, 111 s (v0.1) and 126.74 s
in the v0.2 full-stack run, exit 0, with `+RTS -N2 -M2500m`. Falsified: none. Timed out: none. No
lemma weakened. Every lemma was also proved in isolation (`formal/perlemma_n4/summary.txt`, all
rc = 0, longest 83 s = D1).

| lemma | property | result (steps) |
|---|---|---|
| `sanity_honest_certificate` | executability: a certificate with zero corruption exists | verified, exists-trace (9) |
| `A1_three_distinct_signers` | A: three pairwise-distinct signers | verified (6) |
| `A2_signer_authorized` | A: each verified signer honestly signed (K,v) or was corrupt before acceptance | verified (162) |
| `A_acceptance_authorized` | A, combined statement | verified (158) |
| `B_conflict_needs_2qN_corrupt` | B | verified (82) |
| `C1_intersection_nonempty` | C: intersection non-empty | verified (34) |
| `C2_intersection_at_least_2qN` | C: intersection ≥ 2q−N | verified (18) |
| `C3_evidence_reachable` | C: extraction can emit evidence | verified, exists-trace (15) |
| `D2_intersection_seats_corrupt` | D: every intersection seat was corrupt before one acceptance | verified (6) |
| `D1_non_frameability` | D: evidence implies corruption strictly earlier | verified (2374) |
| `E1_below_threshold_no_conflict` | E: ≤ 1 corrupt ⇒ no conflicting pair | verified (82) |
| `E2_at_threshold_conflict_exists` | E: exactly 2 corrupt ⇒ a conflicting pair exists | verified, exists-trace (22) |

E2's attack trace, as Tamarin found it: corrupt `s0`, `s1`; a certificate `{s0,s1,s2}` on `v1` from
three honest `Sign` steps; a certificate `{s0,s1,s3}` on `v2` from adversary-forged signatures of
`s0`, `s1` plus one honest `Sign` by `s3`. The intersection is exactly the corrupt set, and the
honest seats each signed once.

## 2. Tamarin, N = 7, q = 5, 2q − N = 3

A deliberately different encoding (`formal/qpt128_quorum_n7.spthy`, generated by
`formal/gen_n7_votes.py`): no crypto terms; signatures are ideal authenticated facts creatable only
by the seat (honest, one candidate per K) or by the adversary holding the seat's key; 21 explicit
5-subset `Accept` rules; 7 `Register` rules.

Recorded (`formal/tamarin_output_n7_perlemma.txt`), verified: `sanity` (8 steps), `A1` (23), `A2`
(4685), `D2` (6), `D2b` unordered corollary (6), `C3` (4). Not completed within 2.5 GB / 6–7 min per
lemma: A (heap), B (timeout 420 s), C1 (timeout), E2 (heap), D1 (heap, 593 s); E1 and C2 only in the
batch run that timed out at 1,200 s. **No lemma was falsified.** The N = 7 two-certificate claims are
therefore established by the exhaustive checker (§3), not by Tamarin.

**Correction (K13).** The v0.2 ledger's "Not done" line says all seven remaining lemmas "are
OOM-killed even at `-M8000m`" on the 15.6 GB host. The recorded per-lemma files do not support the
sweep: `formal/perlemma_n7_8g/RESULT.txt` says, in full,

> `OOM-killed at -M8000m on a 15.6 GB host with ~5 GB MemAvailable; A/B/C1 exit 137 after 194/204/265 s; queue stopped to protect the production sanitizer runs`

and the per-lemma files themselves record `### exit 137` for **A (194 s), B (204 s), C1 (265 s) and
C2 (209 s)** — four lemmas, of which the summary line names three — while `E2` has no exit line at
all and `D1`, `E1` were never started (the queue was stopped). So: resource-limited, partially
executed, nothing falsified; not "all seven OOM-killed".

The resource-limited failures are also **not stable across runs**, which is itself the evidence that
they are resource effects: in the `-M2500m` loop logs (`formal/perlemma_n7/summary*.txt`) `A2`
records rc = 251 (heap, 253 s), `B` rc = 124 (timeout) twice, `C1` rc = 124, `E2` rc = 251, `A`
rc = 251 — yet the later per-lemma batch records `A2` verified with 4,685 steps in 156 s. Same
theory, same statement, different memory pressure: a lemma that is verified on one run and
heap-exhausted on another is resource-limited, not falsified.

## 3. The bounded checker (third model)

`formal/bounded_checker.py`, recorded `formal/bounded_checker_output.txt`, 0.45 s. Exhaustive over
honest choices (3^H for two candidates) and over every certificate signer set; for N ≤ 7 every
corrupt subset of size C is enumerated, for N = 10 the corrupt set is fixed to `{0…C−1}` (the model
is permutation-invariant, so this is WLOG); a three-candidate re-check is run for N ≤ 5.

| N | q | 2q−N | result |
|---|---|---|---|
| 4 | 3 | 2 | boundary exact at C = 2; min intersection 2; honest never named; every C ∈ 0…4 and every corrupt subset enumerated |
| 5 | 4 | 3 | boundary exact at C = 3; min intersection 3 |
| 7 | 5 | 3 | boundary exact at C = 3; min intersection 3; all 2^7 corrupt subsets |
| 10 | 7 | 4 | boundary exact at C = 4; min intersection 4; A and C hold for every certificate; honest never named |

Boundary assertions pass for every N: `C = 2q−N−1` ⇒ no conflicting pair; `C = 2q−N` ⇒ a pair whose
intersection is entirely corrupt (e.g. N = 7: certificates `[0,1,2,3,4]` and `[0,1,2,5,6]`,
intersection `[0,1,2]`).

## 4. ProVerif — recorded as unexecuted, executed for this repository

`formal/qpt128_quorum.pv` (C = 2) and `formal/qpt128_quorum_C1.pv` (C = 1): same abstraction as the
N = 4 Tamarin theory (ideal message-recovering signature, a table of registered keys, a
`restriction` enforcing one candidate per (seat, K), a verifier needing three verifying signatures
of pairwise-distinct seats, an extractor taking two conflicting signatures of one seat). ProVerif
cannot count corruptions, so C is fixed per file by publishing exactly C keys.

**Recorded state: unexecuted.** The audit host had no ProVerif, so these files are marked
"read-checked, never executed" and the expectations written in their headers are expectations, not
observations. The verification environment for this repository **does** provide ProVerif (2.05), and
both models were run for this repository on 2026-09-13 — transcripts `results/proverif-run/qpt128_quorum.out`
(C = 2, 0.35 s, exit 0) and `results/proverif-run/qpt128_quorum_C1.out` (C = 1, 0.25 s, exit 0). This is the one
place where a recorded "unexecuted" became an observation; the recorded ledger rows are left as
recorded and the difference is listed in `README.md` and `VERIFICATION.md`.

Observed, query by query (all eight/nine queries answered, no inconclusive result):

| variant | query (as modelled) | recorded expectation | observed |
|---|---|---|---|
| C = 2 | A: an accepted certificate's seats each signed or are corrupt | true | true |
| C = 2 | A': a verified signature is the seat's or the seat is corrupt | true | true |
| C = 2 | D: evidence names only a corrupt seat | true | true |
| C = 2 | D': two verified signatures of one seat are equal or the seat is corrupt | true | true |
| C = 2 | B/C: conflict ⇒ same candidate or both `s0`, `s1` corrupt | true (trivially) | true |
| C = 2 | E2: conflict ⇒ same candidate | **false**, attack trace | false, trace found (forged `s0`, `s1`) |
| C = 1 | A, A', D, D' | true | true |
| C = 1 | E1: conflict ⇒ same candidate | **true** (the meaningful test of B) | true |
| C = 1 | sanity: `Accept` reachable | reachable | reachable (negated query false) |
| C = 1 | sanity: `Evidence` **not** reachable | not reachable (`not Evidence` true) | **falsified — `Evidence` is reachable** |

The last row is a genuine disagreement between a model and its own documented expectation, found by
the first execution of that model. The recorded counter-example trace is exact and short: the
adversary reads the published `sk0` (`Corrupt(s0)` at step 10, `out(c, sk0)` at 11) and submits
`sign((a, a_1, s0), sk0)` and `sign((a, a_2, s0), sk0)` as two signatures of seat `s0` on
conflicting transcripts, so the extractor fires `Evidence(s0, a, a_1, a_2)`. Because those terms are
built by the adversary with the `sign` constructor, no `Signed` event accompanies them, so the
one-candidate `restriction` does not block the trace — and no two *accepted* frames are derivable,
which is why E1 (`Accept` twice ⇒ same candidate) still holds. The security-relevant queries are
therefore unaffected (`Evidence ⇒ Corrupt` still holds, D), and the model is not refuted; its sanity
expectation was simply wrong about a model in which a corrupt seat's key is published to the
adversary. Under the source's label
discipline this is a **model-or-ledger expectation falsified by measurement**, and it is reported as
such rather than repaired in the header. Syntax requirement in the recorded files: ProVerif ≥ 2.04.

## 5. EasyCrypt — a skeleton, unexecuted

`formal/frame_b0.ec` states the FRAME(B0) → EUF-CMA reduction with loss N, with the game-hop plan in
comments; the proof is `admit`ted and no EasyCrypt binary exists on the host, so nothing is
machine-checked. Three defects are visible in the file itself, each checkable by opening it at the
named construct (they are reading findings, not compiler output, since nothing ever compiled it —
they are recorded here, not repaired): the `Frame_Adv` interface is declared over an oracle
`sign(i, m)` while the scheme it is instantiated with expects the `Scheme` interface (`Frame_Adv`
and `section`); the `corrupted` set is initialised with `corrupted <- fset0` and never updated, so
corruption is not modelled at all; `EUF_CMA.O.sign` references `EUF_CMA.sk`, declared after the
submodule that uses it. A reader should treat the file as a plan, not as a proof.

## 6. Modelling artifacts (not protocol violations)

Recorded in `formal/FINDINGS.md` §6, all caught before or during the runs and none of them a
property violation:

- **A lemma-statement bug caught before any run.** The first `D2` required corruption before *both*
  acceptances. A seat may honestly sign `v1`, be corrupted afterwards, and have its `v2` signature
  forged — so the correct claim is `k < i | k < j`. The original statement would have been falsified
  by that legitimate trace. Tamarin, both ProVerif files and the checker all use the corrected
  statement.
- **Tractability rewrites, none changing the trace set.** A generic 3-variable `Accept` rule with a
  4-way seat disjunction exhausted memory (kept as `qpt128_quorum_generic.spthy`, unproven) and was
  replaced by four explicit 3-subset rules; `Eq(verify(..), true)` (2³ equational variants per rule)
  became pattern-matching against the registered `pk(sk)` under the `signing` theory; `[reuse]` of
  A1/A2 split Signed/Corrupt for all six abstract signers before resolving any `Accept` node (2⁶
  branches, heap exhaustion), so A2 is `hide_lemma`d in every two-certificate lemma; the N = 7
  theory uses per-seat `Register` rules (A2 went from heap exhaustion to 4,685 steps) and one
  `!CertSig` fact per signer so `Extract` matches the shared seat directly.
- **A guarded N = 7 C2 statement.** C2 is stated "for any two signers `s,t` of certificate 1 there
  is a common signer `u` outside `{s,t}`" (equivalent to `|intersection| ≥ 3`); the direct `∃ s t u`
  form made Tamarin case-split into trivially-true disjuncts.

## 7. Discrepancies between the models

None found. Tamarin N = 4 (symbolic signatures), Tamarin N = 7 (ideal votes; single-certificate
lemmas plus D2), ProVerif (expected only) and the exhaustive checker agree: the boundary sits at
C = 2q−N, the intersection has at least 2q−N seats, and it is a subset of the corrupt set.

## 8. Honest limits

- Tamarin proves A–E for N = 4 (and the recorded N = 7 lemmas) with unboundedly many coordinates,
  candidates, certificates and sessions — **but for those N only**. Nothing here proves N = 64,
  q = 43 except through the same counting structure that the checker verifies exhaustively for
  N ≤ 10 and that the implementation relies on for the ratified 22 shared signers.
- The symbolic models assume EUF-CMA-ideal ML-DSA, honest seats that never double-sign a coordinate,
  unique seat registration, and a verifier that checks seat-identity distinctness. Transcript/seat
  binding, duplicate-signer checks and coordinate encoding in the implementation are outside this
  layer and belong to the code audit.
- The reachable state spaces are bounded as stated (N ≤ 10 exhaustively; small-N Tamarin theories);
  "no counterexample" is a statement about those spaces, not about the deployed 64-seat system.
